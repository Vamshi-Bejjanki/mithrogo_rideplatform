# website

Static marketing site (plain HTML, no build step): `index.html` (landing page), `privacy.html`, `terms.html`.

- The landing page explains the platform, the two captain plans and how to join.
- `privacy.html` and `terms.html` are drafts marked for legal review. Replace `support@example.com` and the [TBD] items before launch (needed for app store listings).
- Download links are added once the apps are published.

Open `index.html` in a browser to preview. It does not talk to the backend.
