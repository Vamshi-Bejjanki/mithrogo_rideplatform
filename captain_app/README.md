# captain_app

Flutter app (Android/iOS) for captains.

Flow: Splash → Login → OTP → KYC → Vehicle → Subscription → Home (online/offline) → Ride request → Accept → Navigate to pickup → Arrived → Start → Complete → Earnings.
Extra: profile, documents, payment history, ride history, ratings, support, settings.

Create with `flutter create` when ready. Background location and WebSockets come in the maps/live-location phase.
